给从 Windows 换到 Mac 的你

New Mac. Same Keys.

Windows 的快捷键，在 Mac 上照样用。

SameKeys 让 Ctrl+C 照样复制，Win+V 照样打开剪贴板历史，鼠标滚轮方向和 Windows 一致。多年的肌肉记忆，不用重新练。

一个软件，五样配齐。

在 Mac 上找回 Windows 的习惯，现有的软件功能比较分散：键盘一个、鼠标一个、剪贴板历史一个……每个都要找、要装、要授权、要设置。SameKeys 把它们一站式配齐，第一次打开就按 Windows 的习惯设好。这也是我做 SameKeys 的初衷。

键盘快捷键

Ctrl+C、Home 和 End、F2：58 个 Windows 快捷键，打开就能用。

鼠标和滚轮

侧键后退前进，fn 或 Ctrl + 滚轮缩放网页，滚轮方向和 Windows 一样。

剪贴板历史

Win+V 打开复制过的内容，可以搜索、可以固定。

窗口分屏

像 Win+← 一样，把窗口放到左半屏、右半屏，或者铺满屏幕。

Finder

Delete、F2、剪切粘贴文件，右键菜单还能新建文档。

手指记得的，都还算数。

很多日常操作，Mac 用的是另一套按键，有的干脆没有。SameKeys 把你按下的键，换成 Mac 认得的那一个。

为换机的人想周全。

什么键盘都行

PC 键盘、Mac 键盘都能用。可以像在 Windows 上一样按 Ctrl，也可以用 fn 代替它，把 Ctrl 留给 Mac 自己的快捷键。二选一，或者两个都要。

不碰终端

在“终端”和 iTerm 里，Ctrl+C 依然用来中断正在运行的程序。SameKeys 知道哪里的 Ctrl 另有用处。

随你调整

整组开关，给任何一条录制别的快捷键，或者写自己的规则，对所有应用生效，也可以只对某一个。

鼠标、触控板各管各

滚轮方向和缩放只改鼠标。触控板手势照旧按 Mac 的方式来。

小巧安静

待在菜单栏里，一键暂停。不用装系统扩展，也不用装键盘驱动。

说你的语言

支持 English、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Português 和 Polski。

剪贴板历史，就像 Win+V。

按 ⌥V，最近复制过的东西就出现在鼠标旁边。选中一条，直接粘贴。

  • 文字、图片、文件都能搜索
  • 常用的内容可以固定
  • 密码管理器里的密码一律不记录
  • 只保存在你的 Mac 上，绝不上传。默认关闭，由你决定是否打开。

访达，用起来像文件资源管理器。

你在文件资源管理器里用惯的按键和菜单，在访达和每个打开、存储对话框里照样能用。

资源管理器的按键

Delete、F2 和回车分别是删除、重命名和打开，退格键返回上一级文件夹。

剪切和粘贴文件

按 Ctrl+X，再到另一个文件夹按 Ctrl+V，文件就移过去了。

右键新建

右键就能新建文本、Word、Excel 或 PowerPoint 文档，拷贝路径，或在终端中打开当前文件夹。

粘贴路径

在访达或对话框里按 Ctrl+Shift+G，粘贴路径就能跳到文件夹或打开文件，就像资源管理器的地址栏。

打开和存储对话框

Ctrl+G 跳到访达里正打开的文件夹，Ctrl+Shift+G 列出最近和收藏的文件夹。

收藏文件夹

在访达的右键菜单里把文件夹加入 SameKeys 收藏，之后在任何对话框里都能直接找到。

两项权限，各有用处。

任何应用想改变按键的作用，macOS 都会先请你允许这两项。

辅助功能

让 SameKeys 把 Windows 快捷键换成 Mac 上对应的那个：你按 Ctrl+C，应用收到的是 ⌘C。没有这项权限，macOS 不允许任何应用改写输入。

输入监控

让 SameKeys 看到普通按键，比如 Ctrl+C 里的 C。没有这项权限，只收得到修饰键、点按和滚动。

你输入的内容只属于你。SameKeys 绝不记录、保存或发送。

SameKeys 不记录任何按键。每次按键它只看一眼，判断是不是要转换的快捷键，然后就放行。没有任何数据统计，每一行代码都是公开的。

常见问题

Mac 上怎么用 Ctrl+C 复制？

macOS 的复制、粘贴和大多数快捷键用的是 ⌘（Command）键。装上 SameKeys 就生效了：Ctrl+C、Ctrl+V、Ctrl+Z、Ctrl+S 等都和在 Windows 上一样。只有终端例外，那里的 Ctrl+C 要用来中断程序。

Mac 上的 Home 和 End 为什么不能跳到行首行尾？

在 Mac 上，Home 和 End 是滚到文档的顶部和底部，行首行尾要按 ⌘← 和 ⌘→。SameKeys 替你转换，Shift+Home、Shift+End、Ctrl+Home 和 Ctrl+End 也都和在 Windows 上一样选中、跳转。

Mac 上鼠标滚轮方向能和触控板分开设置吗？

macOS 本身不行：一改“自然滚动”，鼠标滚轮和触控板就一起反过来。在 SameKeys 的“鼠标”页打开“Windows 滚动方向”，滚轮就和 Windows 一样，触控板和妙控鼠标仍保持自然滚动。

用苹果键盘也可以吗？

可以。Control 键就在 PC 键盘上 Ctrl 的位置。如果想把 Ctrl 留给 Mac 自己的快捷键，可以改用 fn，按 fn+C 复制。

SameKeys 免费吗？

免费，并以 GNU 通用公共许可证第 3 版开源。任何人都可以阅读、编译和改进它的代码。如果它帮你省下了一些烦躁，可以赞助这个项目，但完全不必。

和 Karabiner-Elements 有什么不同？

Karabiner-Elements 擅长改单个按键、做多层键位，功能强大。SameKeys 只做一件事：在 Mac 上沿用 Windows 的习惯，第一次打开就能用，还管鼠标和滚轮，而且不需要装系统驱动。

SameKeys 会联网吗？

只在检查更新时联网，每天一次。它只读取本网站上的版本列表，不会发送任何关于你或你的 Mac 的信息；新版本也要你点了才会安装。在“关于”页关掉“自动检查更新”，SameKeys 就完全不联网。

Mac 上怎么剪切、粘贴文件？

访达没有“剪切文件”：要先用 ⌘C 拷贝，再用 ⌥⌘V 移动。装上 SameKeys 后，Ctrl+X、Ctrl+V 移动文件就和 Windows 上一样；右键菜单还能新建文档、在终端中打开当前文件夹。

能像 Win+← 那样把窗口吸附到半屏吗？

可以。装上 SameKeys 后，⌥+← 和 ⌥+→ 把最前面的窗口放到左半屏或右半屏，⌥+↑ 铺满屏幕，⌥+↓ 最小化。在 Mac 键盘上，⌥ 正好在 Windows 键的位置。macOS 15 起系统也自带 fn+Ctrl+方向键。
