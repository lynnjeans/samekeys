• Setup guide: choose its language; its last step turns on the features that start off.
  • Finder: Ctrl+V pastes copies, and moves only after Ctrl+X; Ctrl+Shift+N makes a new folder.
  • Browsers: Ctrl+Shift+N opens a private window.
  • Terminals inside apps: in VS Code and similar apps, Ctrl keys go to the terminal unchanged.
  • Wheel zoom: follows each keyboard's Ctrl key.
  • Win and Alt keys: the choice is now drawn on the keyboard.
  • Password fields: when an app in the background holds Secure Input and shortcuts pause, the menu bar says which app.
  • Clipboard history: copying in remote desktop apps no longer stalls keys.
